Mochy Backup

Mochy Backup is the cloud backup feature built into Mochy Ext, an open-source Android music player (GPL-3.0). It lets users voluntarily back up and restore their own music library metadata, playlists, and app settings using their personal Google Drive account.

What Mochy Backup Does

  • Creates encrypted/packaged backup archives of your local app settings and playlist library.
  • Uploads backup files only to the user's own Google Drive when requested or scheduled by the user.
  • Restores previously created Mochy Backup archives onto the user's device.

Google API Compliance

Mochy Backup only requests narrow Google Drive access strictly needed to save and restore app backup files created by the user. It does not read unrelated files, does not sell or share user data, and does not use Google APIs for any AI training or image generation.
